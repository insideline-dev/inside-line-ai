Branch dev @ 1b90f1c, 2026-05-20. Walk this top-to-bottom in one sitting (~90 min). Every numbered checkpoint cites the backlog ID it verifies. Items marked SKIP are MVP-defer / Icebox and you can ignore them.

How to use this doc

  • Sections 1-3 are setup. Sections 4-12 are the actual journey, in order.
  • Every checkpoint has a Story ID, Action, and Expected. Tick the box mentally (or in a copy of this doc) as you go.
  • If a checkpoint fails, jot down the section + step number and the actual behavior. Don't try to "fix it on the fly" — finish the journey first to see whether failure cascades.
  • You'll need two accounts and one deck. See § 1.

Story: DS-E3-F1-S1
